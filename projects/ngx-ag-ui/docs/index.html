ngx-ag-ui

Angular Library for Agentic UIs with Google ADK

🤔 What is this?

ngx-ag-ui helps you build chat interfaces where an AI agent can interact with your Angular app.

🎯 Simple Example

Imagine a chatbot that can:

  • Read your app's current state (like a shopping cart)
  • Update things in your UI (like adding items)
  • Ask you for approval before doing important actions

📚 Key Concepts

1. 🛠️ Actions (Frontend Tools)

Things the agent can do in your app.

provideAction({
  name: 'add_to_cart',
  description: 'Add a product to the shopping cart',
  handler: async ({ productId }) => {
    // This runs in YOUR browser
    this.cartService.add(productId);
    return { success: true };
  }
});
2. 📖 Readables (Context)

Information you share with the agent.

provideReadable({
  description: 'Current user preferences',
  value: {
    language: 'en',
    currency: 'USD',
    theme: 'dark'
  }
});
3. 🔌 Adapter

The connector between your Angular app and the AI backend.

const adapter = new AgAdkAdapter({
  url: 'http://localhost:8001/api/my-agent'
});

🛠️ How provideAction Works

⚠️ Important to Understand

The handler function stays in your browser. Only the name and description go to the backend.

What Gets Sent to Backend

┌─────────────────────────────────────────┐ │ YOUR ANGULAR APP │ │ │ │ provideAction({ │ │ name: 'show_summary', │ │ description: 'Display summary', │ │ parameters: [...], │ │ handler: async (args) => { ... } ◄───┼── Handler stays here! │ }); │ └───────────────┬─────────────────────────┘ │ │ Only schema sent ▼ │ ┌───────────────▼─────────────────────────┐ │ ADK BACKEND │ │ │ │ Receives: │ │ { │ │ name: 'show_summary', │ │ description: 'Display summary', │ │ parameters: [...] │ │ } │ │ │ │ ❌ Handler is NOT here! │ └─────────────────────────────────────────┘

When Agent Calls the Tool

1. Backend: "I want to call show_summary with args" │ ▼ 2. Frontend receives TOOL_CALL_END event │ ▼ 3. Adapter checks: Do we have a handler for 'show_summary'? │ ▼ 4. YES → Execute handler IN THE BROWSER │ ▼ 5. Send result back to backend

✅ Safe! The handler code never leaves your browser. The backend only knows the tool exists, not how it works.

📖 How provideReadable Works

Shares data FROM your app TO the agent as context.

┌─────────────────────────────────────────┐ │ YOUR ANGULAR APP │ │ │ │ provideReadable({ │ │ description: 'User preferences', │ │ value: { theme: 'dark' } │ │ }); │ └───────────────┬─────────────────────────┘ │ │ Sent with each message ▼ │ ┌───────────────▼─────────────────────────┐ │ ADK BACKEND │ │ │ │ Context: "User preferences: { │ │ theme: 'dark' │ │ }" │ │ │ │ Agent uses this to give better │ │ responses tailored to the user. │ └─────────────────────────────────────────┘
⚠️ Don't share sensitive data

The value is sent to the backend. Don't include passwords or secrets.

🔌 AgAdkAdapter

The adapter is your single connection to an agent endpoint.

What it handles automatically:
  • Message streaming (character by character)
  • Tool call tracking (show spinners, status)
  • Agent handoffs (sub-agent name changes)
  • Predictive state updates
  • Frontend tool execution
@Injectable()
export class MyAgentService {
  // Create adapter with endpoint URL
  private adapter = new AgAdkAdapter({
    url: 'http://localhost:8001/api/my-agent',
    
    // Execute frontend tools when backend calls them
    onToolCallEnd: async (id, name, args) => {
      if (this.context.hasHandler(name)) {
        return await this.context.executeAction(name, args);
      }
      return null; // Backend handles it
    }
  });

  // Expose reactive signals
  messages = this.adapter.messages;      // Chat messages
  activities = this.adapter.activities;  // Tool call status
  isLoading = this.adapter.isLoading;    // Loading state
}

🔒 Security Notes

✅ Handlers are safe - They never leave your browser.

⚠️ Be careful with readables

Anything in provideReadable() is sent to the backend.

📋 Checklist
  • ✅ Action handlers execute in browser only
  • ✅ Only tool schemas (name, description) go to backend
  • ✅ One adapter per endpoint (enforced)
  • ⚠️ Don't put secrets in readable values
  • ⚠️ Validate tool call args before using them
